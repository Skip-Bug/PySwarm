# 🐝 PySwarm

Инструмент для распределенного нагрузочного тестирования REST API с удобным веб-интерфейсом.

## 🚀 Особенности
- **FastAPI** для бэкенда и раздачи дашборда.
- **Locust** (FastHttpUser) для генерации высокой нагрузки.
- **WebSockets** и **Chart.js** для живых графиков в реальном времени.
- **Docker & Docker Compose** для запуска в один клик.
- **Архитектура Master/Worker**: позволяет масштабировать нагрузку, задействуя все ядра процессора.
- **Динамическая конфигурация**: задержки, токены и лимиты настраиваются прямо в UI.

## 🛠 Быстрый старт (Docker)

Убедитесь, что у вас установлен и запущен Docker Desktop. Выполните в терминале:

```bash
docker compose up -d --build
```

После сборки откройте в браузере: http://127.0.0.1:8000

Чтобы остановить контейнеры, выполните:

```bash
docker compose down
```

## ⚡ Как масштабировать нагрузку

По умолчанию запускается 1 воркер. Если вам нужно сгенерировать десятки тысяч RPS, запустите больше воркеров (например, 4):

```bash
docker compose up -d --scale locust_worker=4
```

Docker автоматически создаст сеть и свяжет всех воркеров с Мастером.

## 📊 Куда сохраняются результаты?

Благодаря пробросу Volume в docker-compose.yml, все результаты тестов (CSV-файлы со статистикой) сохраняются на вашем компьютере в папке `tmp/`. После завершения теста их можно открыть в Excel или Pandas для детального анализа.

## 📝 Формат JSON для загрузки

В интерфейсе дашборда можно загрузить JSON-файл со списком запросов. Пример:

```json
[
  {
    "method": "GET",
    "url": "/api/users/1",
    "headers": {"Authorization": "Bearer token"}
  },
  {
    "method": "POST",
    "url": "/api/orders",
    "body": {"item_id": 5, "quantity": 2}
  }
]
```

## 📌 Важно при тестировании локальных сервисов

⚠️ **Внимание:** Контейнеры работают в изолированной сети. Если вы тестируете сервис, запущенный на вашем компьютере (а не в Docker), в поле «Целевой URL» указывайте `http://host.docker.internal:8000`. Если написать `http://127.0.0.1:8000`, воркеры будут стучаться сами в себя и нагрузка не пойдёт.
